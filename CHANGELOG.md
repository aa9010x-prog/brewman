# Журнал изменений brewman

## 1.7.2 – 24.11.2026
- Исправлена диагностика ошибки «Failed to download …jws.json» при brew update: это не повреждённый кэш, а известная проблема Homebrew с загрузкой файла «по дате» относительно сохранённой копии.
- Исправление теперь точечное: удаляется сохранённая копия только этого файла и запускается brew update --force; весь кэш очищается, лишь если это не помогло.
- Исправление можно делать автоматически, без вопросов: brewman предлагает это после первого удачного раза, переключатель – пункт 6 меню «Обновления».

## 1.7.1 – 23.11.2026
- В поиске программ не из Homebrew (пункт 14) справочно показываются другие пакеты той же программы с версиями, например «другие пакеты: firefox@beta (122.0b3), firefox@esr (115.6.0esr)».

## 1.7.0 – 23.11.2026
- Новый пункт 14 главного меню: поиск программ, установленных не через Homebrew, у которых есть готовый пакет (cask), и передача их под управление Homebrew (--adopt) – программа и её настройки остаются на месте.
- Для каждой программы показываются установленная версия и версия в Homebrew; если одной программе соответствует несколько пакетов (например, бета-версии), выбирается основной.
- Программы из App Store и уже управляемые Homebrew пропускаются.
- Если Homebrew отказался брать программу (обычно из-за другой версии), brewman предлагает заменить её версией из Homebrew (--force) с сохранением настроек.
- Справочник программ Homebrew загружается не чаще раза в сутки; при недоступности сервера используется сохранённая копия.

## 1.6.4 – 23.11.2026
- Новые версии brewman видны сразу после публикации: проверка идёт через API GitHub, а не через сервер raw.githubusercontent.com, который кэширует файлы до 5 минут.
- Если API GitHub недоступен, используется raw.githubusercontent.com с обходом кэша, затем gh или токен.
- При ручной проверке показывается источник и версия в репозитории.

## 1.6.3 – 20.11.2026
- Ctrl+C снова работает: в меню и на любом вопросе закрывает brewman. Раньше в macOS он срабатывал только после нажатия Enter.
- Ctrl+C во время команды brew прерывает только её и возвращает в меню; прерывание не считается ошибкой и не запускает диагностику.
- При установке, удалении или обновлении нескольких пакетов Ctrl+C останавливает текущий пакет, остальные пропускаются.

## 1.6.2 – 20.11.2026
- Если brew update не смог обновить индекс, brewman проверяет доступность сервера Homebrew и называет вероятную причину: повреждённый кэш, сеть или VPN, сбой на стороне Homebrew.
- При повреждённом кэше предлагает очистить его и повторить обновление, в остальных случаях – повторить или подождать.
- Если индекс так и не обновился, список устаревших пакетов выводится с предупреждением и датой сохранённых данных.

## 1.6.1 – 18.11.2026
- Обновления скачиваются из публичного репозитория без входа в GitHub (через curl); gh и токен остаются запасными способами для приватного репозитория.

## 1.6.0 – 18.11.2026
- Самообновление из приватного репозитория GitHub: проверка раз в сутки при запуске, пункт 13 главного меню, команды brewman --update и brewman --rollback.
- Доступ к репозиторию через утилиту gh или токен с правом только на чтение (хранится в связке ключей macOS).
- Перед установкой загруженный файл проверяется: синтаксис, принадлежность к brewman, совпадение версии; предыдущая версия сохраняется для отката.

## 1.5.0 – 18.11.2026
- Все меню приведены к вертикальному виду (раздел «Информация о пакете»).

## 1.4.0 – 18.11.2026
- Распознавание ошибки «Полный доступ к диску»: инструкция для текущего терминала и открытие нужного раздела настроек.

## 1.3.0 – 18.11.2026
- Распознавание конфликта «It seems there is already an App»: повтор удаления с --force, при установке – выбор --adopt или --force.

## 1.2.0 – 17.11.2026
- Поддержка доверия к сторонним репозиториям (Homebrew 6): предложение brew trust и повтор команды, меню управления доверием.
- Версии приложений cask берутся из папки Caskroom, если brew list не может загрузить описания.

## 1.1.0 – 17.11.2026
- Запасные способы получить список приложений cask и диагностика вместо «Список пуст».

## 1.0.0 – 17.11.2026
- Первая версия: просмотр, поиск, установка, удаление, обновление пакетов, сервисы, pin, tap, Brewfile, обслуживание.
